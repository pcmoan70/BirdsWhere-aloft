# BirdsWhere — Migration Aloft

**Live site: https://pcmoan70.github.io/BirdsWhere-aloft/**

Production site for the Migration Aloft radar map (GitHub Pages). This repo holds
**only the servable site**: `index.html`, the `aloft-*.js` client, and the `tiles/`
data window. It is generated from the private `Birdswhere_aloft_workspace` repo
(template, build, and the radar/weather pipeline) and should not be edited by hand.
